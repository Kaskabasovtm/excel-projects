# excel-projects
Тест-кейсы для аналитика · Excel

Три практических задания в формате тестовых заданий работодателей.

1. Товарооборот по территориям

Проект задание 2.1 Тестирование Аналитик.xlsx

Данные: ежедневный товарооборот (шт. и руб.), заказы, клиенты и склады по 18 территориям, конец апреля – начало июня 2020.
Сделано: сводная таблица, топ-3 территорий за последнюю полную неделю (по доле в товарообороте и по товарообороту на склад), понедельная динамика с графиком.
Неполные недели в начале и конце периода выявлены и исключены из графика, чтобы не искажать динамику.
2. Визуализация, структурирование данных и группы для A/B-теста

Проект задание 2.2 Assignment.xlsx

Диаграммы продаж и долей товаров.
Приведение неструктурированных данных к таблице, сегментация абонентов по трафику с шагом 5 ГБ.
Из базы ~21 600 номеров сформированы тестовая и контрольная группы по 3 000 номеров, сопоставимые по ключевым показателям (наличие смартфона, ARPU, регион). Равенство групп проверено статистически (z-тест).
3. Тест-кейс по биллингу абонентов

Проект задание 2.3 Excel test case Novartis Pharma Services AG гот.xlsx

Инструменты

Excel: сводные таблицы, СУММЕСЛИМН, СЧЁТЕСЛИМН, СРЗНАЧЕСЛИМН, ИНДЕКС + ПОИСКПОЗ, ВПР, РАНГ, НОМНЕДЕЛИ, диаграммы
